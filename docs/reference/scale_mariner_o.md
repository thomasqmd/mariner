# Ordinal colour and fill scales for mariner

Ordinal colour and fill scales for mariner

## Usage

``` r
scale_colour_mariner_o(reverse = FALSE, ...)

scale_color_mariner_o(reverse = FALSE, ...)

scale_fill_mariner_o(reverse = FALSE, ...)
```

## Arguments

- reverse:

  Logical; if `TRUE`, reverses the color ramp.

- ...:

  Arguments passed to
  [`ggplot2::discrete_scale()`](https://ggplot2.tidyverse.org/reference/discrete_scale.html).

## Value

A ggplot2 discrete scale object tailored for ordered categories.
