# Formats shipped by mariner

The Quarto formats the extension contributes.

## Usage

``` r
mariner_formats
```

## Format

A character vector.

## Details

There is one: `pdf`, through xelatex. mariner turns a parameterized
`.qmd` into a report, and a report is a PDF.

It stays a vector for the same reason
[mariner_themes](https://thomasqmd.github.io/mariner/reference/mariner_themes.md)
does.
