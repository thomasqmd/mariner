# Themes shipped by mariner

The brand identities available to
[`mariner_setup_project()`](https://thomasqmd.github.io/mariner/reference/mariner_setup_project.md)
and the templates. Every function that takes a `theme` argument
validates against this vector.

## Usage

``` r
mariner_themes
```

## Format

A character vector.

## Details

There is one theme today. It stays a vector, and `theme` stays a named
argument everywhere rather than being dropped, so adding a second
identity later is a new entry here rather than a signature change across
the package.
